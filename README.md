# CRM Campaign Management Checklist

A practical checklist template for managing multi-channel 
CRM campaigns using tools like CleverTap and MoEngage.

## Campaign Channels Covered
- Mobile Push Notification
- Web Push
- Email / Newsletter
- WhatsApp Blast
- Facebook Ads

## Checklist Includes
- Pre-campaign setup
- Audience segmentation checklist
- QA before launch
- Post-campaign review metrics

## Purpose
Built from real experience managing 5+ campaigns/month 
for enterprise clients across various industries.
